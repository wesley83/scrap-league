## Mobile graphics repair — October 16, 2026

The user reported a white 3D surface with Chromium's broken-canvas marker on a Pixel 11 Pro running Edge. The exact device trigger and cached release are unknown. The game now defaults coarse-pointer devices to safer graphics (no multisample antialiasing or dynamic shadows, DPR capped at one, one-million-pixel allocation budget). A lost or empty drawing buffer is checked independently before simulation; shader/allocation failures enter the same stopped-race recovery path.

Mobile preference migration keeps existing controls and adopts safer graphics when the old preferences have no graphics-profile choice.
